# src/engine_subsystems/space_bridge/space_pure.h

This header holds the pure functions of the module: the tests, the math, the split and the set. The unit programs of the tests include it.

`space_set_t` is a set of ids: its slots, its room and its count: `docs/intern/engine_subsystems/space_bridge/space_set.c.md`.
The other prototypes belong to `docs/intern/engine_subsystems/space_bridge/space_check.c.md`, `docs/intern/engine_subsystems/space_bridge/space_math.c.md`, `docs/intern/engine_subsystems/space_bridge/space_local.c.md`, `docs/intern/engine_subsystems/space_bridge/space_split.c.md` and `docs/intern/engine_subsystems/space_bridge/space_rotation.c.md`.
