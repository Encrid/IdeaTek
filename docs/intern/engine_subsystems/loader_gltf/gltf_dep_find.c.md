# src/engine_subsystems/loader_gltf/gltf_dep_find.c

This file finds a dependency by its use entity, or by its file, its kind and its index.

## Functions

| Function | Result |
| --- | --- |
| `find_dep` | The dependency of a use entity, or nothing. |
| `find_dep_of` | The dependency of a buffer or an image of a file, or nothing. |
