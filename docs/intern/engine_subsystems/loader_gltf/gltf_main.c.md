# src/engine_subsystems/loader_gltf/gltf_main.c

This file holds the manifest of the glTF loader, and its entries `init`, `shutdown` and `reload`.

`init` declares the types, spawns the loader and adds the observers. The module has no system. `shutdown` and `reload` give 0.

## Functions

| Function | Result |
| --- | --- |
| `init` | Declares the types, spawns the loader entity, and adds the 6 observers. Gives 0. |
| `shutdown` | Gives 0. |
| `reload` | Gives 0. |
